PERFORMANCE BOTTLENECK AUDIT — 2026-08-22
Baseline (this machine, loaded; rankings matter, absolutes vary ~2x):
  harness cap=1024 (~407 units, ~395 projectiles): SIM-ONLY p95 50.2ms = 100.4% of the
  20Hz fixed-step budget. Phase ranking: combat.projectiles 10.6ms, combat.targetingFsm
  5.6ms, sim.pathfinding 4.8ms (already budgeted — the model), combat.targetingStamp
  4.4ms, core.physics 2.6ms (poolResolveSphereSphere 1.9ms/tick boundary), core.unitForces
  1.9ms, combat.fireTurrets 1.5ms. Render: per-object rig meshes dominate draw calls.

BAR reference idioms adopted (from ../Beyond-All-Reason survey): unitID%N==tick%N
sharding; sliding-index work queues with chunk = clamp(len/interval, 32, 1024);
timer wheels for computable due-times; watch-lists never scans; expensive call always
INSIDE the cadence guard; distinct phase offsets per system; when a tick is coarsened,
rescale the effect so gameplay is cadence-invariant.

Verification rules for every item: cargo test + tsc + targeted contract tests; for
RESULT-IDENTICAL claims, A/B the harness against SAME-HEAD and confirm identical
live-unit counts / replay hashes; behavior-change items land as their own commits.

Legend: [RI] = result-identical (bit-identical replay). [BC] = deterministic behavior
change (lockstep-safe, replay hashes move).

================ GROUP P — combat.projectiles (top rock, 10.6ms) ================

P0  [RI] No sub-phase visibility inside combat.projectiles. Add sub-phases
    (integrate/reflector/sweep/terminal/presentation) around the five blocks in
    SimulationCombatController.updateProjectileCombat.

P1  [RI] Terminal classify+plan = ~35 wasm malloc/copy/free triplets PER PROJECTILE
    PER TICK (projectileTerminalConsequenceBatch count=1 with 25 in-slices + 4 out +
    4 heap objects; then projectileTerminalEffectPlanBatch 5+1+1). ~45k allocations/
    tick at 1300 projectiles. Rewrite both kernels as one scalar+staged single
    (flags packed in u32, outputs in a WASM-resident staging block), same call order.
    Largest single structural item in the pipeline.

P2  [RI] Sweep exclude lists: packProjectileSweepExcludes rebuilds + SORTS the
    removed-entity union per projectile (O(P x R log R), grows with battle
    intensity); Rust then linear-scans it (entity_id_in_slice per candidate AND per
    turret sub-hitbox). Fix: append-only removals prefix kept resident in staging +
    per-projectile tail; drop both sorts (nothing consumes order); Rust-side bitset
    membership.

P3  [RI] Shield gates recompute per-pair invariants: shield_field_pose_bound (prev+
    curr pose + sqrt) per (projectile x shield) pair, and mirror-panel cos/sin yaw/
    pitch per (projectile x unit x panel). Stamp union bounds per shield and trig
    per unit/panel once per tick at stamp time.

P4  [RI] Sweep internals: 3 separate cells.get passes per cell (units/buildings/
    projectiles — ~81 probes per projectile, most misses); dedup is an FxHashSet
    with a capacity-sized clear() per sweep. Fix: one key->bucket resolve pass, then
    epoch-stamp Vec<u32> dedup. Keep kind-priority order (tie behavior unchanged).

P5  [RI] No per-cell max-radius/AABB rejection in SpatialCellBucket, and the query
    band is sized by world-global monotone getMaxTargetableRadius (one big building
    permanently widens every projectile's corridor). Add per-cell maxima maintained
    on insert; conservative cell pre-reject.

P6  [RI] Reflector batch: 31+24 JS-owned arrays marshalled per tick — and the BEAM
    tracer calls the same kernel count=1 PER SEGMENT (31 mallocs x up to 6 segments
    per beam). Move to WASM-resident ReflectorStaging with ptr views + detach
    discipline; beam path reuses row 0.

P7  [RI] terrainSurface polls sim.terrainIsInstalled() on EVERY sample (2 crossings
    per getGroundZ/isWaterAt) — ~2600 wasted crossings/tick in terminal classify
    alone, ~18 per beam segment. Cache in a module boolean invalidated on install.
    Also: move findGroundSegmentT's 12+6 sample loop into one Rust call.

P8  [RI] presentation_capture_tick copies a used_slots PREFIX that is a monotone
    high-water mark with no shrink path — after a 2500-projectile peak, every tick
    copies 2500 rows (~380KB) forever, plus an O(used) id-mismatch pass. Decay
    used_slots on trailing-slot release; fold the mismatch pass into capture().

P9  [BC] spatial_fill_occupied_cells_in_bounds emits cells in FxHashMap bucket
    order — deterministic today but load-bearing on cell insert/remove history,
    which BLOCKS grid-cell persistence. sort_unstable() the packed keys (one-time
    replay-hash move; own commit).

P10 [RI after P9] Grid-cell persistence: stop pruning empty cells on remove (3 hash
    probes + remove/insert pair per boundary crossing, grid rebuilt twice/tick).
    The known ~5% HashMap-churn fix. MUST land after P9.

P11 [BC] beamConfig collisionSampleIntervalTicks is 1 — the entire hashed tick-ring
    amortization + damage-window accumulator machinery exists and is a no-op.
    Raise to 2 (DPS preserved by the window accumulator; hit timing coarsens).

P12 [RI] Small: world.getEntity(sourceHost) fetched unconditionally for arming when
    isArmed already early-outs (~1300 wasted Map.gets/tick); motion-event drain
    allocates its sort comparator per tick.

================ GROUP T — combat.targetingFsm + targetingStamp (10ms combined) ====

T2  [RI] The SAME (turret -> target) LOS is computed twice per tick: lock validation

T3  [RI] refreshSlabActivityMasksForUnit = 3 crossings x every armed entity x every

    write views then call the batch once.

T4  [RI] Cooldown reads/writes in fireTurrets each pay 2 crossings for
    combatTargetingTurretSlabIndex when _fireTargetingContext already holds
    views+turretBase — read views.cooldown[turretBase+i] directly.

T5  [RI] entity_has_enabled_weapon + reset_disabled_weapons run for every entity

T6  [BC] has_active_work counts a turret merely slewing back to rest, keeping its

T8  [BC] There is no global acquisition budget (the pathfinding model). Add a

T9  [RI] Small: stamp an entity_has_slaved_mount bit to skip apply_slaved_mount_
